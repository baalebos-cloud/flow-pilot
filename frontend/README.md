# FlowPilot × BMONI — Flutter Frontend

A polished, dark-first fintech frontend for a hackathon demo of an AI financial action copilot.

## Demo flow

`Goal → AI Understanding → Plan → Policy Check → Review → Approval → Proposal → Signing → Processing → Success`

The default app uses deterministic mock services. No backend, AI API key, bank credential, database, or BMONI credential is required.

## Run

1. Install Flutter 3.22+ and Dart 3.3+.
2. From this directory run:

```bash
flutter create .
flutter pub get
flutter run
```

`flutter create .` is only needed if platform folders were not generated by your Flutter installation. It will preserve the existing `lib/` and `pubspec.yaml` files.

## Demo

Open **FlowPilot**, tap the suggested demo prompt, then follow the review and approval flow. The mock wallet starts at **₦300,000.00** and the demo withdrawal is **₦100,000** with a **₦500** fee. After success, the displayed balance becomes **₦199,500.00**.

The success screen explicitly identifies the transfer as a demo transaction and does not claim to have moved real money.

## Architecture

- `models/` — domain models and JSON contracts
- `services/` — replaceable service interfaces
- `mock/` — deterministic local implementations
- `providers/` — Riverpod state
- `features/` — screens by product capability
- `core/widgets/` — reusable UI primitives
- `app/theme/` — design system

### BMONI integration boundary

`BmoniService` is intentionally an abstraction. The included `MockBmoniService` simulates signing/status behavior. No undocumented BMONI SDK methods are assumed. A real adapter can be added later without coupling screens to SDK implementation details.

## Backend configuration

`.env` contains:

```text
API_BASE_URL=http://localhost:8000
```

`ApiClient` is ready for future FastAPI integration, while the current app remains entirely local.
